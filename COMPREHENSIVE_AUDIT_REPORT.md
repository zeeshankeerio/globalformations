## 🎨 **Standardized Design System**

### **Colors**
```css
Primary: #2563eb (Blue 600)
Secondary: #059669 (Emerald 600)
Accent: #0ea5e9 (Sky 500)
Success: #10b981 (Emerald 500)
Warning: #f59e0b (Amber 500)
Error: #ef4444 (Red 500)
```

### **Typography**
```css
Headings: Space Grotesk (Bold)
Body: DM Sans (Regular/Medium)
Sizes: text-xs to text-7xl (consistent scale)
```

### **Spacing**
```css
Sections: py-16 (standard)
Large Sections: py-20 (hero, major features)
Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
```

### **Components**
```css
Cards: border border-slate-200 bg-white shadow-lg
Buttons: Consistent sizing and styling
Badges: Unified color scheme and typography
```
